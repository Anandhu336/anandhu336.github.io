# Digital Portfolio

My personal portfolio website - a record of my journey, achievements and dreams. Live at https://anandhu336.github.io

## Sections

- Home - quick introduction
- About - background, education and experience
- My Skills - technical and professional skills
- Portfolio - a showcase of my work
- Blog - latest posts
- Contact - how to reach me

## Tech stack

- HTML5 / CSS3
- Bootstrap
- jQuery

## Getting started

```bash
git clone https://github.com/Anandhu336/anandhu336.github.io.git
cd anandhu336.github.io
open index.html
```

Or just visit the live site: https://anandhu336.github.io

## Project structure

- `index.html` - the whole site (single page)
- `assets/` - images, styles and other static assets
- `favicon.ico` - site favicon
